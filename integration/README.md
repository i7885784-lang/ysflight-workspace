# Записи изменений для других чатов

Каждая задача добавляет **новый отдельный файл** в `changes/` по `templates/CHANGE_REPORT.md`. Указывайте исходную версию, изменённые файлы, реальные проверки, оставшиеся ошибки, материалы и откат. Статус по умолчанию `candidate`; `accepted_by_owner` меняется только после явного подтверждения владельца. Чат сборки читает новые подтверждённые записи и записывает общую сборку в `shared/release/INTEGRATION_STATUS.md`. Другие чаты получают записи только после обновления Git.
