# Записи подтверждённых изменений для других чатов

`changes/` содержит **только результаты, которые владелец явно подтвердил**. До подтверждения чат держит код, кадры и отчёт в своей ветке и показывает результат владельцу в своём чате; запись сюда не добавляется. После подтверждения создаётся отдельный файл по `templates/CHANGE_REPORT.md` со статусом `accepted`, точной базой, изменёнными файлами, проверками, остаточными багами и откатом. Другие чаты получают запись после объединения ветки с `main` и обновления Git. Чат сборки использует эти записи для общей сборки и фиксирует её в `shared/release/INTEGRATION_STATUS.md`.
