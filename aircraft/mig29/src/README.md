# Исходники

Здесь находятся выборочные редактируемые исходники. Перед изменением проверьте, из какой версии игры они взяты и какие файлы нужны для полной сборки.

Добавлен исторический набор редактируемого кода из старого репозитория. Это примерная исходная точка для работы, **не полный воспроизводимый пакет**: бинарные модели, большие upstream-ресурсы, движок и входная игровая сборка в этот лёгкий Git не переносились. Перед правкой сверяйте базу и зависимости по исходному отчёту.
