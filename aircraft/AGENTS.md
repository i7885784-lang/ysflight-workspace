# Правило для задач по самолётам

Откройте `PROJECT.md` и `COLLABORATION.md` в корне, затем `PROJECT.md` в назначенной папке самолёта. Читайте соседний самолёт только если конкретная зависимость записана в задаче. Работайте в ветке задачи. Меняйте код и отчёт своего самолёта; правку общего движка явно записывайте и согласуйте через `shared/flight/`. Добавьте отдельный файл в `integration/changes/` по шаблону. Сохраняйте входную основу, ссылку на результаты и честный список непроверенного. Не называйте кандидат принятой общей игрой без интеграционной проверки.
