# Правило для чата самолёта

Читайте `PROJECT.md` и `COLLABORATION.md` в корне, затем свою папку самолёта. До подтверждения меняйте только её `src/`, `work/` и `PROJECT.md` в своей ветке. Запись в `integration/changes/` создавайте только после явного подтверждения владельца. Можно читать `shared/` для понимания зависимостей; не меняйте общий движок, карты, сборку и другие самолёты. Для общего изменения опишите проблему владельцу. Сравнивайте игровые результаты до/после и продолжайте доводку, если стало лучше. Не упрощайте геометрию и не трогайте другую модель без отдельного поручения. Кандидат остаётся кандидатом, пока владелец его не подтвердил.
