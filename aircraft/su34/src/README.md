# Исходники этой области

Размещайте здесь только новые или изменённые файлы этой области. Для каждого изменения укажите точную базовую версию и путь назначения в полной игре в отчёте задачи. Если исходник движка общий для нескольких самолётов, размещайте его в `shared/flight/src/` и отмечайте зависимости.

Добавлен исторический набор редактируемого кода из старого репозитория. Это примерная исходная точка для своей области, **не полный воспроизводимый пакет**: бинарные модели, большие upstream-ресурсы, движок и входная игровая сборка в этот лёгкий Git не переносились. Перед правкой сверяйте базу и зависимости по исходному отчёту.
