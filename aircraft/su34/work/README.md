# Задачи и результаты

Для каждой задачи создавайте отдельную папку `YYYY-MM-DD-короткое-имя/` с `REPORT.md` по шаблону из `templates/CHANGE_REPORT.md`. Сюда можно положить несколько небольших показательных PNG/JPG и подписи к ним. Полные наборы кадров, видео и ZIP сохраняйте в GitHub Release или старом архиве и указывайте ссылку и SHA в отчёте. Папка задачи должна быть понятна другому чату без чтения всей истории.
