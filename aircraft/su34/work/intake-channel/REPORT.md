# Су-34: весь внутренний проход впуска

По последнему уточнённому рисунку владельца затемнены дно, боковые стенки и потолок обоих проходов. После принятия этого вида владелец попросил отодвинуть чёрные задние поверхности ещё дальше: теперь обе наZ=-3.10м, на75см глубже промежуточногоZ=-2.35. Геометрическая глубина отначала существующей внутренней облицовки2.75м.

Причина прежнего неправильного вида: затемнялась только часть внутренних поверхностей, а длинные треугольники дна2184/2188/2190 и зеркальные2799/2800/2801 оставались светлыми. Старый ограничитель minZ=-3.49 отсекал их целиком, поскольку они тянутся доZ≈-3.816; также прежнее требование точной совпадающей обратной грани пропускало отдельные внутренние поверхности. Точные видимые полигоны найдены отдельным диагностическим кадром с уникальным цветом каждого полигона; это диагностическое окрашивание в итог не перенесено.
