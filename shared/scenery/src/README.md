# Исходники этой области

Размещайте здесь только новые или изменённые файлы этой области. Для каждого изменения укажите точную базовую версию и путь назначения в полной игре при передаче результата. Если исходник движка общий для нескольких самолётов, размещайте его в `shared/flight/src/` и отмечайте зависимости.
