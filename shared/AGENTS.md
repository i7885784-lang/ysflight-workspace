# Правило для общих частей

Читайте корневые `PROJECT.md` и `COLLABORATION.md`, затем только назначенную папку `shared/`. Любая правка движка, карты или общей сборки может повлиять на несколько самолётов: перечислите их и проведите соответствующую регрессию. Запишите изменения в отдельном файле `integration/changes/`; обновите `shared/release/INTEGRATION_STATUS.md` только после общей сборки и проверки.
