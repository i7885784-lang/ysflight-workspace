# Правило для чатов общих частей

Читайте корневые `PROJECT.md` и `COLLABORATION.md`, затем свою папку `shared/`. Чат движка может читать самолёты для проверки общего изменения, но не меняет их модели молча. Чат карт ведёт карты. Чат сборки объединяет только подтверждённые владельцем правки и проверяет их вместе. Каждый оставляет отдельную запись в `integration/changes/` и отчёт о результатах. Принятие следующей общей версии решает владелец.
