# Сборка игры

Основной чат отвечает и за общую игру. Для каждой готовой версии он публикует полный игровой ZIP в GitHub Releases и даёт прямую ссылку на скачивание. Для Windows x86 и x64 нужны отдельные файлы и ссылки. Изображения результата публикуются в GitHub и открываются обычной ссылкой в браузере. Достаточно коротко описать, что изменено и что реально проверено; обязательный журнал задач не нужен.

[Стартовые архивы Су-30СМ](../../BASE_GAME_ARCHIVES.md) можно использовать для работы, но они не считаются первой принятой версией. Права на модель Су-34 требуют проверки до публикации сборки с этой моделью.
