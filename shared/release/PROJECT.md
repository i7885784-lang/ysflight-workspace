# Общая сборка и выпуск

Чат сборки читает `PROJECT.md`, `COLLABORATION.md` и записи `integration/changes/`, которые владелец подтвердил после последней общей сборки. Несколько правок можно собрать вместе. Проверить точные входные версии, совместимость моделей и движка, работу всех затронутых самолётов и общих функций. Конфликт общего C++ кода передавать владельцу и чату движка, который делает один рабочий вариант. Итог: `INTEGRATION_STATUS.md`, ZIP и SHA, краткие кадры/видео по характеру правок. Решение о включении в общую игру принимает только владелец. Права на модель Су-34 проверяются до публичной или коммерческой поставки.

Для выдачи каждой новой общей сборки предоставить владельцу ссылку на отчёт с фото и две прямые ссылки на полные игровые ZIP Windows x86/x64. Не вкладывать старые версии внутрь новых ZIP и не копировать их в рабочий Git; прежние сборки сохранять в исходном архиве и релизах.
