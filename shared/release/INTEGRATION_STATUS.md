# Общая сборка

Интеграция в этом лёгком репозитории ещё не выполнена. Полная игра и прежние сборки находятся в исходном архиве. Прежде чем назвать новую сборку общей, указать точные коммиты всех задач, входную базу, результат проверки совместимости, ссылки на ZIP и контрольные суммы.

Стартовые [ZIP Су-30СМ](../../BASE_GAME_ARCHIVES.md) не являются подтверждённой общей версией и не участвуют в объединении. Первая подтверждённая владельцем версия будет первой общей версией. Объединение начнётся после появления второй подтверждённой версии.
