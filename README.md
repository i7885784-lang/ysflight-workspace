# YSFlight — общая рабочая площадка

Здесь совместно разрабатываются **вся игра, все самолёты, полёт группой и карты**. Репозиторий лёгкий: краткая карта проекта и отдельные папки задач. Полная историческая игра, старые сборки, исходники движка и медиа находятся в [исходном архиве](https://github.com/i7885784-lang/igraYS-Flight-Simulator). Сохранённый здесь снимок работ 15 ноября лежит в `archive/`; он служит справкой, не готовой самостоятельной сборкой.

**Начните с [PROJECT.md](PROJECT.md).** Затем откройте только свою папку в `aircraft/` или `shared/` и её `AGENTS.md`. Для параллельной работы прочитайте [COLLABORATION.md](COLLABORATION.md). Не надо при каждом запросе читать весь исходный архив.

## Направления

| Папка | Предмет |
|---|---|
| `aircraft/su27/` | Су-27 |
| `aircraft/mig29/` | МиГ-29 |
| `aircraft/su30sm/` | Су-30СМ |
| `aircraft/su34/` | Су-34, с отдельным ограничением по правам |
| `aircraft/su47/` | Су-47 |
| `aircraft/su57/` | Су-57 |
| `shared/flight/` | Игровой движок, управление, ведомые, интерфейс |
| `shared/scenery/` | Карты и окружение |
| `shared/release/` | Общая сборка, совместимость и поставка |
| `integration/changes/` | Короткие записи о выполненных задачах всех чатов |

`main` — общая карта и собранные изменения. Для каждой задачи создавайте ветку вида `task/su27-описание` или `task/flight-описание`. После проверки объединяйте её через pull request. Одна постоянная ветка на самолёт плохо передаёт изменения общего движка и со временем расходится с остальными; границу работы задаёт папка и запись задачи.
