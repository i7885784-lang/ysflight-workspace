# YSFlight — лёгкая рабочая карта

Этот репозиторий содержит небольшой набор исходников и отчётов последней линии работы над Су-30СМ. Он нужен, чтобы помощник читал десятки файлов вместо тысяч. Полный архив игры и всех прежних опытов сохранён в [основном репозитории](https://github.com/i7885784-lang/igraYS-Flight-Simulator).

**Статус:** это рабочий контекст, а не принятая пользователем «готовая версия» и не самостоятельная полная сборка игры. Баги остаются. Последний собранный кандидат в этой линии — `fix/su30sm-control-base-20261115` исходного репозитория. Закреплённая точка отката там — Су-30СМ тест №5 с правкой впуска (`CURRENT_VERSION.json`). Перед новой правкой указывайте конкретную сборку, от которой следует продолжать.

## Как читать

1. Прочитайте `README.md` и `PROJECT_STATE.md`.
2. Для задачи по управлению читайте `changes/su30sm-control-base/`, `changes/su30sm-high-alpha/` и соответствующие `reports/`.
3. Для задачи по соплам читайте `changes/su30sm-nozzle-vector/` и её отчёт.
4. Полный игровой архив, предыдущие генераторы модели, C++ движок, фотографии и видео берите из исходного репозитория только по необходимости. Не обходите весь его Git при каждом вопросе.

Папки `changes/` здесь содержат точные копии исходников из ветки `fix/su30sm-control-base-20261115`, а `reports/` — относящиеся к ней текстовые результаты. Часть скриптов ссылается на полный архив игры, `dist/`, предыдущие исходники и GitHub Releases; для сборки их нужно восстановить из исходного репозитория. Запуск скриптов прямо из этой лёгкой копии без этих входных данных не поддерживается.

Новые задачи оформляйте отдельными ветками от `main` этого репозитория, например `fix/su30sm-gear` или `fix/su30sm-controls`. При этом добавляйте только файлы, нужные для задачи. Большие ZIP и медиа храните в релизах или исходном архивном репозитории.
