# Авиационная игра на основе YSFlight

Один основной чат Codex работает над всей игрой: самолётами, движком, картами и сборкой. При необходимости владелец может дать отдельную небольшую задачу второму чату. [Описание игры](PROJECT.md) · [Текущее состояние](PROJECT_STATE.md) · [Стартовые ZIP игры](BASE_GAME_ARCHIVES.md).

В `aircraft/` находятся материалы самолётов, в `shared/` — общие части игры. Это папки для удобства, а не границы доступа. Основной чат может менять любые нужные файлы проекта и сам проверяет, что всё работает вместе.

После готовой правки чат публикует полный игровой ZIP в **GitHub Releases** и даёт **прямую ссылку на файл ZIP**. Если подготовлены обе архитектуры, нужны отдельные ссылки для Windows 32 и 64 бит. Изображения результата публикуются в [`screenshots/`](screenshots/) на GitHub и даются ссылками, которые открываются в браузере. Вложение только в чат не подходит. Короткого описания результата и непроверенных вещей прямо в ответе достаточно; обязательный блог и длинные отчёты не нужны.

Сейчас в репозитории есть выборочные исходники и материалы старой работы, но ещё нет полной согласованной игры для воспроизводимой сборки. Полный старый проект: [igraYS-Flight-Simulator](https://github.com/i7885784-lang/igraYS-Flight-Simulator). Не объявлять готовой новую сборку, пока полный ZIP реально не создан и не проверен.
