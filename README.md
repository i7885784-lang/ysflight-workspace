# Пилотажная группа — общая рабочая площадка

Здесь ведётся работа над всей авиационной игрой на основе YSFlight. [Что за игра и что уже решено](PROJECT.md) · [Как работают несколько чатов](COLLABORATION.md) · [Что ещё надо обсудить](docs/ОТКРЫТЫЕ_ВОПРОСЫ.md).

Игрок задуман как ведомый в пилотажной группе: тренировки, выступления, полёты с командой и друзьями. Бои не планируются. Замысел может уточняться владельцем.

В `aircraft/` есть Су-27, МиГ-29, Су-30СМ, Су-34, Су-47, Су-57, а также новые направления Су-35С и Як-130. Папки `aircraft/` разделяют самолёты, `shared/flight/` — движок, `shared/scenery/` — карты, `shared/release/` — общую сборку. Каждый чат работает в отдельной ветке своей задачи. В `integration/changes/` он передаёт запись другим чатам только после твоего подтверждения; общая `main` получает её после объединения ветки. [Исторический архив проекта](https://github.com/i7885784-lang/igraYS-Flight-Simulator) хранит полную игру, старые версии, исходники и медиа. Этот репозиторий пока содержит карту и выборочные исходники, но не полный согласованный игровой runtime.

Папки и ветки задают организационные границы, а не технический запрет чтения внутри одного GitHub-репозитория. Чат самолёта меняет только свой самолёт; общий движок меняет отдельный чат. Пользователь подтверждает, какие правки входят в общую игру.

После задачи чат даёт владельцу [отчёт с фото и прямые ссылки на Windows x86/x64 ZIP](COLLABORATION.md#что-чат-обязан-передать-владельцу-после-правки). Старые сборки остаются в исходном архиве и релизах.
