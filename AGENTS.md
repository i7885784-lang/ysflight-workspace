# Правило для помощников

Сначала прочитайте `README.md`, `PROJECT.md` и `COLLABORATION.md`. Затем откройте только папку своей задачи и её ближайший `AGENTS.md`. Не сканируйте весь старый архив или `archive/` без конкретной необходимости. Работайте в отдельной ветке задачи. Чат самолёта меняет только свой самолёт, свои отчёты и запись в `integration/changes/`; общий движок, карты, сборку и чужие самолёты он может читать лишь для конкретной зависимости и не меняет. Нужную правку общего кода предложите владельцу для передачи чату движка. Решение о принятии изменения и общей сборки принадлежит владельцу.
