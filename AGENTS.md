# Работа над игрой

Прочитайте `README.md`, `PROJECT.md`, `PROJECT_STATE.md` и описание области текущей задачи. Работает один основной чат: он может править самолёты, движок, карты и сборку по мере необходимости. Не требуется создавать отдельный чат или ветку для каждого самолёта, вести общий журнал либо писать длинные отчёты.

После готовой задачи дайте владельцу короткое описание изменений, честно перечислите реальные проверки и предоставьте прямые ссылки на полный игровой ZIP в GitHub Releases и на изображения результата в `screenshots/` на GitHub. Если есть две архитектуры, дайте отдельные ссылки на x86 и x64. Проверяйте, что ссылки открываются без авторизации; не выдавайте исходники или непроверенный архив за готовую игру.
