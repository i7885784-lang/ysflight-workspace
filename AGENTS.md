# Рабочее правило для помощников

Сначала прочитайте `README.md`, `PROJECT.md` и `COLLABORATION.md`. Выберите одну область `aircraft/<самолёт>/` или `shared/<часть>/` по задаче пользователя и прочитайте её `PROJECT.md` и ближайший `AGENTS.md`. Не сканируйте весь старый архив и `archive/` при каждом запросе. Если нужны точные входные исходники, откройте лишь соответствующий отчёт и Sources ZIP из старого репозитория. Создавайте отдельную ветку задачи и отдельную запись в `integration/changes/`; общий релиз собирается через `shared/release/`. Пользовательские слова о текущей задаче важнее старых записей.
